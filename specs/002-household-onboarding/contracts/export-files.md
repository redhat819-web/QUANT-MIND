# 내보내기 파일 계약

모두 브라우저에서 `.xlsx`로 만든다(research R7). 서버는 파일을 만들거나 보관하지 않는다.
파일명에는 날짜를 넣지 않고, 내려받는 순간의 기준 시점은 파일 안의 `정보` 시트에 적는다.

## 1. 내 자산 내보내기

- 누가: 모든 구성원(탈퇴 기간 중 포함)
- 파일명: `quantmind-my-assets-v1.xlsx`
- 형식: `asset-template-v1.md`와 **같은 머리글·시트 구조**. 그대로 다시 올리면 같은 계좌·종목이
  복원되어야 한다(SC-011).
- 범위: 내 개인 명의 계좌만. 공동·자녀 계좌는 넣지 않는다.

## 2. 판단 로그 내보내기

- 누가: 모든 구성원. 탈퇴 기간에는 화면에서 이 내보내기를 안내한다(FR-014b, FR-014c, FR-014d).
- 파일명: `quantmind-judgment-log.xlsx`
- 범위: 내보내는 사람이 지금 RLS로 읽을 수 있는 household의 판단 로그 전체.

| 시트 | 열 |
|---|---|
| 안건 | 제목, 내용, 작성자, 작성 시각, 상태 |
| 의견 | 안건 제목, 의견, 작성자, 작성 시각 |
| 합의 | 안건 제목, 확정자, 확정 시각, 확정 시 의견 수 |
| 변경 이력 | 안건 제목, 수정자, 수정 시각, 사유, 이전 제목, 이전 내용 |
| 정보 | 내보낸 시각, 삭제 예정 안내(탈퇴 기간일 때) |

- 작성자·확정자·수정자는 화면 표시 이름("나", "상대방", 이름, "떠난 구성원")으로 적는다. 이메일과
  사용자 id는 넣지 않는다.

## 3. 상대 자산 포함 여부

- 남는 사람이 내보낼 때 떠나는 사람의 자산 금액은 상대의 `shares_assets`가 true인 동안에만 들어간다.
  RLS가 이미 그렇게 거르므로 내보내기 로직에 별도 분기를 두지 않는다(FR-014c).
- 판단 로그에는 금액 필드가 없다.
